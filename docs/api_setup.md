# API 키 설정과 집계 기준

프로젝트 루트 `app.py` 옆의 `.env`에 키를 넣습니다. 기존 `.env`는 유지하고 `.env.example`의 새 항목만 추가하세요. 모듈 폴더의 `.env.example`은 참고용이며 실제 설정은 루트에서 읽습니다. 키를 수정한 뒤 화면을 새로고침하면 다음 조회에 반영됩니다.

## 화면별 연결

| 환경변수 | 발급·공식 안내 | 적용 화면 |
|---|---|---|
| `CUSTOMS_API_KEY` | [관세청 품목별 수출입실적(GW)](https://www.data.go.kr/data/15101609/openapi.do) 서비스키 | 첫 화면 한국 수출액·성장률·연도별 선그래프 |
| `CUSTOMS_COUNTRY_API_KEY` | [관세청 품목별 국가별 수출입실적(GW)](https://www.data.go.kr/data/15100475/openapi.do) 서비스키 | 첫 화면 주요 수출 시장 막대그래프·전체 국가 표 |
| `COMTRADE_API_KEY` | [UN Comtrade](https://comtradeplus.un.org/) 개발자 API subscription key | Tab 3 선택 국가의 한국산 수입액·수입액 성장률·점유율·추이 |
| `EXCHANGE_API_KEY` | [ExchangeRate-API](https://www.exchangerate-api.com/)에서 발급받은 인증키 | Tab 2 환율 계산기 |
| `KOTRA_API_KEY` | [KOTRA 해외시장뉴스](https://www.data.go.kr/data/15034831/openapi.do) 서비스키 | Tab 3 선택 국가의 화장품 기사 |
| `OPENAI_API_KEY` | [OpenAI API](https://platform.openai.com/api-keys) 키 | Tab 3 유통사 웹 검색·Tab 1 선택적 CSV 열 분류 |

관세청 두 서비스와 KOTRA는 각각 활용 신청·승인이 필요합니다. 같은 공공데이터포털 키로 두 관세청 서비스가 승인되어 있다면 `CUSTOMS_COUNTRY_API_KEY`는 비워도 됩니다. `CUSTOMS_API_KEY`를 대신 사용합니다. 공공데이터포털 키는 Decoding/Encoding 형식을 처리하되 Decoding 키 입력을 권장합니다.

환율은 [ExchangeRate-API](https://www.exchangerate-api.com/docs/standard-requests)의 KRW 기준 응답을 사용합니다. 이 서비스에서 발급받은 키를 루트 `.env`의 `EXCHANGE_API_KEY`에 넣으세요. 서버에서 Bearer 인증으로 호출하며 키를 브라우저에 보내지 않습니다.

키가 없는 서비스는 기존 등록 JSON을 표시합니다. 키가 있어도 인증·활용 승인·호출 한도·제공처 장애 때문에 실패하면 화면에 오류를 표시합니다. 실패를 0원/0%로 바꾸거나 샘플 데이터를 실제 데이터처럼 표시하지 않습니다.

## 품목과 기간

```dotenv
COSMETICS_HS_CODES=3304
TRADE_YEARS=5
TRADE_END_YEAR=
COMTRADE_HS_VERSION=H6
OPENAI_MODEL=gpt-4.1-mini
```

- 기본 HS 3304는 미용·메이크업·기초화장품 등의 범위입니다. 향수·두발용 제품 등을 포함한 모든 화장품 총계와 동일하지 않습니다. 팀에서 결정한 화장품 HS 4/6자리 코드 목록을 쉼표로 입력하세요. 상위 코드와 그 하위 코드를 동시에 입력하면 중복 집계를 막기 위해 거부합니다.
- 수출과 수입이 같은 `COSMETICS_HS_CODES`를 사용합니다. 화면에 HS 범위·기간·단위·제공처를 함께 표시합니다. 모델이 품목 범위를 임의 추정하지 않습니다.
- 기본은 최근 완료된 5개년입니다. 예를 들어 2026년에 실행하면 2021~2025년을 요청합니다. `TRADE_END_YEAR=2025`처럼 종료 연도를 고정할 수 있고 `TRADE_YEARS`는 2~10입니다.
- 관세청은 한국 신고 수출액(FOB, USD)입니다. 12개월 전체 또는 제공처의 연간 합계만 연간 총수출액에 사용합니다. API의 월별 행과 합계 행을 중복 합산하지 않습니다. 최신 완료 연도 자료가 아직 없으면 자료가 있는 마지막 연도와 비교 기간을 화면에 명시합니다.
- Comtrade 기본 HS 버전은 H6(2022), H5는 2017, H4는 2012입니다. 보고국·파트너·기간·수입 흐름·HS 버전·운송/통관 집계 조건이 일치하는 행만 사용합니다. 제공처의 미보고/누락은 0으로 추정하지 않습니다.

성장률은 `(현재액-이전액)/이전액×100`이며, 직전 비교 연도 금액이 누락되거나 0이면 표시하지 않습니다. 첫 화면은 한국 수출액 성장률, Tab 3은 해당 국가의 한국산 수입액 성장률입니다. 수입 점유율은 `해당 국가의 한국산 수입액 / 해당 국가의 전 세계 수입액 × 100`으로 계산합니다. 현지 소매시장 전체에서 한국 브랜드가 차지하는 점유율과는 다릅니다.

## 국가와 권역

홈의 국가 순위는 서비스 목적지 7개로 제한하지 않습니다. 관세청의 공식 국가 코드 목록으로 국가·지역별 데이터를 조회하고, 실제 응답이 있는 국가를 수출액 순으로 정렬합니다. 상위 5개는 막대그래프, 전체는 펼쳐 보는 표에 표시합니다. EU 합계는 회원국과 중복되므로 국가별 조회에서 제외합니다. 국가별 총합이 전체 수출액과 일치하지 않으면 불완전한 순위를 표시하지 않고 오류를 알립니다.

목적지는 러시아(EAEU)·EU·UAE·미국·일본·중국·ASEAN입니다. EU·ASEAN은 실제 목적 회원국을 별도로 선택합니다. ASEAN의 선택 범위는 요청한 아래 10개국입니다.

| 코드 | 국가 | 코드 | 국가 |
|---|---|---|---|
| TH | 태국 | VN | 베트남 |
| ID | 인도네시아 | SG | 싱가포르 |
| MY | 말레이시아 | PH | 필리핀 |
| BN | 브루나이 | MM | 미얀마 |
| KH | 캄보디아 | LA | 라오스 |

EU/ASEAN 자체를 수입 API의 국가로 전송하지 않고 실제 선택 국가를 Comtrade reporter로 전송합니다. 러시아(EAEU)는 RU 통계이며 EAEU 전체 합계로 표시하지 않습니다. 국가별 기사·유통사 검색도 같은 목적국을 사용합니다.

## CSV·AI·유통사

성분 CSV는 자동으로 이름·CAS·함량 열을 찾고 미리보기를 제공합니다. AI 사용 체크가 꺼져 있으면 외부로 전송하지 않습니다. 체크했을 때만 첫 12행을 OpenAI로 전송하여 열의 위치를 분류합니다. 결과를 확인하고 필요하면 열 선택을 수정한 뒤 적용하세요. AI는 CAS나 함량을 채우거나 법적 적합 판정을 내리지 않습니다.

유통사 후보는 Responses API의 웹 검색 결과를 사용합니다. 모델의 `source_url`이 실제 반환된 검색/인용 출처에 있어야 후보로 표시합니다. 검색 근거와 확인 날짜를 표시하며 AI 검색 후보임을 구분합니다. 업체에 연락을 보내는 기능은 없습니다. 모델 접근 권한이나 웹 검색 지원이 다르면 `OPENAI_MODEL`에 사용 가능한 모델을 설정하세요.

OpenAI 요청은 `store=false`이며 유통사 검색에는 실제 처방 대신 국가와 제품 유형만 전달합니다. 공식 구현 참고: [웹 검색](https://developers.openai.com/api/docs/guides/tools-web-search), [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs).

## 환율·관세·기사

환율은 ExchangeRate-API의 KRW 기준값을 사용하며 API가 알려준 실제 갱신일을 표시합니다. 각 통화의 값을 원화 기준 1통화 가격으로 변환해 계산합니다. 제공하지 않는 통화나 잘못된 값은 임의 환율로 계산하지 않습니다. 무료 요금제의 환율은 하루에 한 번 갱신됩니다.

관세는 외부 API를 호출하지 않습니다. 팀에서 `tab2_customs/data/<country>/tariffs.json`을 작성합니다. ASEAN은 `asean/VN/`, `asean/TH/`처럼 실제 목적국별로 작성합니다. 나머지 회원국 자료가 없으면 준비 중으로 표시합니다. 10개 목적국별 입력용 빈 파일을 준비했으며, 다른 국가의 세율로 대신하지 않습니다.

KOTRA는 실제 목적국 이름과 화장품 검색어로 조회하고 제목·발행일·원문 링크를 표시합니다. 기사 전체 본문은 복제하지 않습니다.

## 캐시와 첫 로딩

국가별 API는 국가 코드가 필수여서 최초 전체 순위 조회에 수백 건의 요청이 필요합니다. 4개씩 병렬 조회하며 인증 실패는 첫 국가 조회에서 중단합니다. 수출 합계·추이와 순위는 따로 불러오므로 지도와 기본 화면은 먼저 사용할 수 있습니다.

수출·수입·기사 캐시는 6시간, 환율 1시간, 유통사 후보 24시간입니다. 국가별 결과도 캐시하며 같은 조회를 동시에 요청해도 중복 호출을 억제합니다. 오류는 60초 후 다시 조회합니다. 키/HS/기간/모델 등 조회 기준이 바뀌면 새로운 캐시를 사용합니다. 강제로 갱신하려면 앱을 종료하고 `instance/api_cache` 폴더만 지운 후 재실행하세요. `beauty.sqlite3`나 `secret.key`는 지우지 않습니다.

환율은 실제 키로 제공처 응답과 계산을 확인했습니다. 나머지 API는 공식 문서의 요청·응답 필드를 사용한 모의 응답 및 브라우저 테스트이며, 실제 발급 키의 승인/과금/제공처 응답까지 검증한 것은 아닙니다. 키를 입력한 후 각 화면의 기간·출처·오류 메시지로 연결 상태를 확인하세요.
