## 2026-09-27 프로젝트 복사 실패 처리

`services/project_service.py`에서 프로젝트 검증·삽입을 재사용하고, 새 프로젝트와 복사 제품을 하나의 트랜잭션으로 저장하도록 수정했습니다. 중간 오류가 발생하면 새 프로젝트와 일부 복사 제품이 함께 취소됩니다. 공개 함수의 인자와 DB 구조는 유지합니다.

`tests/test_workflows.py`에 임시 DB와 합성 제품을 사용하는 회귀 테스트를 추가했습니다. 두 번째 제품 삽입 오류로 수정 전의 빈 프로젝트 잔존 문제를 재현했고, 수정 후 전체 취소·원본 보존·재시도 성공을 확인했습니다. `platform_core/tests`의 14개 테스트가 모두 통과했습니다.
